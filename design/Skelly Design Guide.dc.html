skelly.

A barebones terminal, built in Rust.

Minimal by design and built for keyboard-driven development in vim, neovim & LazyVim. Multi-pane splits, per-repo git diff, and a rewindable session timeline — specified here end-to-end so nothing is left to guess.

How to read this document

This is a design guide, not source code and not a finished product. Every screen shown is a static mockup describing intended layout, tokens, and behavior. Navigation & surfaces

There is no separate “git mode” or “timeline screen.” The terminal pane tree is always the base layer and never closes. Git diff and the session timeline open as a right dock over your live terminal; the command palette is a centered overlay; settings is a full in-window view with the terminal still running underneath. Everything is reached the same three ways — a keybinding, the command palette, or a utility-bar icon — and dismissed with Esc (or the same key again).

Rule for the build: docks and overlays are layers, not routes. Opening git diff does not unmount the terminal, focus returns to the exact pane on close, and only one right-dock surface (git or timeline) shows at a time — toggling the other swaps the dock’s content.

10.4

Multi-pane splits

Tile as many panes as you need inside one tab — split horizontally or vertically, and nest splits so they need not be even (below: a full-height editor beside a stacked terminal + logs). Up to 8 panes. The focused pane gets a border.strong ring; drag any divider (1px line, 6px hit area) to resize. ⌥Z zooms the focused pane to full, again to restore.

10.7

Session timeline — rewind & fast-forward

A clickable record of everything done this session — human and agent actions, plus system events. Scrub the track (or click any entry) to restore the codebase to that moment; later events dim to show they’re in the “future.” Fast-forward or hit Return to now to jump back to HEAD. Restoring is non-destructive — it checks out a shadow worktree, never rewriting history.

13 — Handoff

Notes for Claude Code

Build Skelly natively in Rust from this spec. Reproduce the layout, tokens, and behavior — not this HTML. Where a decision is genuinely a product call, it’s flagged under Confirm first rather than guessed.

~/.config/skelly/config.toml single source of truth · UI is a view over it 
[appearance]
theme            = "ossein-dark"   # or ossein-light, kanagawa, tokyonight…
font_family      = "JetBrainsMono Nerd Font"  # any installed font; Nerd Font for neovim icons
font_fallback    = ["Symbols Nerd Font", "Noto Color Emoji"]
font_size        = 14
line_height      = 1.2
ligatures        = true
cursor           = "block"          # block | bar | underline
bold_is_bright   = true
bg_blur          = 18
opacity          = 0.98

[sidebar]
width            = 240            # 180–360; <180 snaps to 56px rail
show_pinned      = true
mode             = "fixed"          # fixed | autohide | hidden · toggle ⌘B

[tabs]
title            = "cwd"            # cwd | command | custom · default = directory name
follow_cwd       = true           # re-title as you cd unless renamed

[panes]
max              = 8
leader           = "ctrl+a"
split_inherits_cwd = true

[session]
timeline         = true
persist          = true           # restore tabs + pinned on launch (layout only)
shadow_worktree  = true           # non-destructive rewind

[git]
diff_view        = "unified"        # unified | split

[keys]
"cmd+k"           = "palette.open"
"alt+bar"         = "pane.split_right"
"alt+minus"       = "pane.split_down"
In scope · v0.1
  • Sidebar tabs, groups, pinning
  • Panes: split H/V, focus, resize, zoom (≤8)
  • Themes: Ossein + preset import
  • Git diff panel with hunk staging
  • Session timeline + rewind
  • Command palette · remappable keys
  • Empty / first-run / error states
Out of scope · later
  • Plugin / extension system
  • In-app AI agent (timeline only records)
  • SSH / remote host manager
  • Windows build
  • Cross-machine tab sync
  • Inline image protocol (kitty graphics)
  • Broadcast-to-all-panes input
Confirm first ⚠
  • How does the timeline receive AI actions? Needs an integration hook/contract, not shell heuristics.
  • Multi-window (multiple OS windows) or single-window?
  • Rewind + edit: fork a branch, or block edits while detached?
  • Persist expectation: layout only, or attempt to re-run processes?
  • Scrollback search scope: active pane vs all panes.
Definition of done
✓Layout matches the dimension tokens at every breakpoint of the sidebar/dock.
✓All UI colors read semantic tokens; switching theme repaints everything live.
✓Every action has a remappable binding surfaced in the palette.
✓Empty, first-run, error, and detached states are all implemented.
✓Timeline rewind is non-destructive (shadow worktree, HEAD untouched).
✓Passes visual review in both Ossein Dark and Ossein Light.
