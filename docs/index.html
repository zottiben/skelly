skelly.

A barebones, keyboard-driven terminal emulator built natively in Rust - minimal by design, for vim / neovim / LazyVim development.

Install · macOS & Linux

$ curl -fsSL https://zottiben.github.io/skelly/install.sh | sh

Already installed? Upgrade in place with skelly update.

  • Multi-pane tiling splits
  • Per-repo git diff dock
  • Rewindable session timeline
  • Zen-style tab sidebar
  • Live theming & Nerd Fonts
  • GPU cell renderer (wgpu)
macOS installs Skelly.app into Applications plus a skelly command; Linux installs the skelly binary on your PATH.
